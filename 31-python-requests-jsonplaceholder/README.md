# 🚀 Python REST Client (Requests CRUD Example)

A simple and clean REST API client built with Python using the `requests` library.  
This project demonstrates how to use HTTP methods: **GET, POST, PUT, PATCH, DELETE**.

The project uses the free test API provided by <span>:contentReference[oaicite:0]{index=0}</span>.

---

## 📌 Features

- ✅ Get all posts (GET)
- ✅ Get a single post by ID (GET)
- ✅ Create a new post (POST)
- ✅ Update a post completely (PUT)
- ✅ Update a post partially (PATCH)
- ✅ Delete a post (DELETE)
- ✅ Simple CLI interface
- ✅ Clean project structure
