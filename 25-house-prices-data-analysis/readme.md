# House Prices Analysis

This project performs an exploratory data analysis on a real-world housing dataset from Kaggle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Scope
- Data loading and inspection
- Handling missing values
- Statistical analysis of housing prices
- Visualization of key market trends

## Key Insights
- House quality has a strong positive impact on sale price
- Newer houses tend to be priced higher
- Location (neighborhood) plays a significant role in pricing

## Dataset
House Prices – Advanced Regression Techniques (Kaggle)
